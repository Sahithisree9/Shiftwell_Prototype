# Shiftwell Smart Shift Approvals

## Run locally
1. Install Python 3.10 or newer.
2. Open a terminal in this folder.
3. Run `python -m pip install -r requirements.txt`
4. Run `streamlit run app.py`
5. Open the local URL shown in the terminal.

## Demo capabilities
- Credential register with expired / expiring / valid status.
- Assignment check that blocks a required expired credential.
- Swap decision simulator for training, credential validity, and weekly-hours threshold.
- Illustrative manager queue.

All data is fictional. This is a local prototype, not a publicly hosted service or production scheduling tool.
